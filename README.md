# АРМ «Записная книжка сотрудников»

Учебный проект по экономическим информационным системам для группы УПАСбд-31. Приложение заменяет разрозненные записи о сотрудниках локальной картотекой: кадровый специалист получает список сотрудников, открывает карточки и видит сумму выплаты по окладу и ставке.

## Этап 1. Предпроектное исследование

Объект учёта — сотрудники организации. На вход поступают идентификационные и кадровые данные; результат работы — список сотрудников, подробные карточки и расчёт выплат. Выбран C#/.NET, чтобы точно считать денежные суммы на `decimal` и обеспечить запуск на Windows и macOS.

## Этап 2. Техническое задание

Локальная картотека позволяет просматривать, добавлять, редактировать и удалять карточки. Поиск работает по ФИО и табельному номеру, фильтры — по отделу и статусу. Данные хранятся в одной таблице SQLite. Сумма выплаты рассчитывается как оклад × ставка и округляется до копеек.

Карточка содержит 12 реквизитов: табельный номер, СНИЛС, дату рождения, дату трудоустройства, ФИО, отдел, должность, контакты, навыки, опыт, статус, оклад со ставкой. Оклад и ставка хранятся отдельно для расчёта. Внутренний ID служит ключом записи.

Среда разработки — Visual Studio Code. Интерфейс картотеки и сообщения проверки ввода — на русском языке. Первый запуск показывает демонстрационный набор вымышленных сотрудников.
