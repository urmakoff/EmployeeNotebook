# Демонстрация на защите

Запустите картотеку по [инструкции](README.md#запуск). Для защиты лучше создать отдельную базу командой:

```sh
dotnet run --project EmployeeNotebook --no-build -- --db ./defense-employees.db
```

1. Покажите исходный список из 12 сотрудников и панель фильтров. Выберите поиск по «Иванов» и отдел «ИТ»: останутся две карточки.
2. Откройте карточку ID 1. Измените ставку Иванова с 1,0 на 1,5: при окладе 85 000 руб. сумма вырастет до 127 500,00 руб.
3. Откройте добавление и введите заведомо неверный СНИЛС. Покажите сообщение об ошибке и отмените сохранение.
4. Добавьте вымышленную карточку с уникальным табельным номером, выйдите через пункт «0» и запустите программу с тем же путём. Найдите сохранённую карточку.

Код разделён на модель и контракты, хранилище SQLite, правила и поиск, консольные представления. `Program.cs` создаёт компоненты и передаёт их в главное представление. Финансовые значения считаются на `decimal`; SQLite хранит их десятичное представление без преобразования в `REAL`.
